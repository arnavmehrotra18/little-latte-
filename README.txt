LITTLE LATTE WEBSITE
1. Open index.html in Chrome/Edge to preview.
2. Keep index.html, style.css and script.js in the same folder.
3. The food photos load from Unsplash, so internet access is required for images/fonts.
4. Before publishing, edit the Visit section in index.html with the cafe address/contact details.
5. To publish free: upload these files to a GitHub repository and enable GitHub Pages in Settings > Pages.
